# 交付版本与两级验收

每个交付版本分别记录。只有 Agent 监修通过的准确版本才能成为交付文件；用户后续否决的历史版本保留并标为需修改。

## 版本记录（每个交付版本复制本节）

- 交付版本、图片文件及内容校验值：待填写
- 来源任务／批次／轮次／候选与原图：待填写
- 参考基线文件及版本：待填写
- 对应 review 文件、版本和内容校验值：待填写
- 交付时间、文件一致性核对及已执行结果：待填写

### Agent 监修

- 通过结论及其实际依据：待填写
- 主要修正与旧问题复核：待填写
- 不阻断交付的建议、证据范围及检查局限：待填写

### 用户验收

- 待验收／需修改／通过：待填写
- 明确验收消息、时间及 feedback 记录：待填写
- 用户意见及已实际处理结果：待填写
- 当前版本／历史版本及后续替代版本：待填写

不得因图片已经保存而填通过。图片或监修报告发生变化后，重新核验对应版本；没有回复时维持待验收。
