核验日期：2026-09-08。供方法审核及更新时读取，不要求每个任务重新调查。没有试跑这些提示词，不把发布者精选样例称为成功率实验。

陶艺师图中，视线和捧碗姿势指向同一个对象，侧窗光强调脸与双手，背景器物补充职业。可迁移的是动作、注意力和环境的关系，不是摄影参数或固定字数。侦探漫画则通过前景人物、后方酒吧、斜雨线和地面反射制造层次；可学习环境怎样帮助表达情绪，不能把其字幕或单人构图带入无文字的多人动作任务。

两张原始成图均为 1024×1024，未满足各自文字中竖幅／横幅的意图。它们有值得学习的画面表达，也有需要核验的失配；不因来源为官方就当作完美范例，不声称它们是“最强提示词”。

对当前流程的改变：先写故事瞬间、镜头和逐人动作，再写效果与环境响应，最后补版本与技术约束。每个细节必须服务画面；删除同义赞词、矛盾视角和为审查方便而强加的展示姿态。身份图不能替代动作证据；参考多不代表输入一致。宏观失败时重新分镜，局部编辑后仍看全图。

这些改变落在 [分镜与提示词](art-direction.md)、[资料](materials.md) 和 [监修](review.md)。它们是待真实任务验证的方法，不是模型训练结果。公开案例只用于学习表达，授权资料库仍是角色事实的唯一依据。
